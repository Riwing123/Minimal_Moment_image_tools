# Minimal_Moment_image_tools
专注于极简社交媒体包装的图片工具箱

把日常，轻轻收藏。

**简像 Minimal Moment** 是一款面向摄影、社交分享的 Android 图片工具箱。它把拼图、分图、色卡、相框和留白画廊放在一个干净轻量的界面里，让照片从选择、排版到高清导出都尽量简单。本软件支持超高像素导出，本人使用时尝试过5亿像素的产品导出。

如果你经常想把多张照片拼成一页、把大图切成 Instagram 九宫格、给照片加一个干净相框、制作右拉长图，或把旅行照片整理成留白画册，它会是一个很顺手的小工具。

## 功能亮点

- **极简界面**：白底、卡片式布局和清晰控件，打开就能开始处理图片。
- **高质量导出**：支持 PNG / JPG 导出，多模块提供原图优先、高清导出和大尺寸导出能力。
- **本地处理**：图片选择、编辑和导出完全在设备本地完成，适合处理私人照片。
- **作品管理**：导出的作品会保存在系统相册中，也可以在应用内的 Works 页面快速回看。
- **适合社交发布**：内置拼图、分图和留白画廊等面向分享场景的排版工具。

## 隐私说明

简像 Minimal Moment 以本地图片处理为主。应用会请求读取相册图片用于编辑，并将导出的图片保存到系统相册。应用完全本地运行、不依赖任何网络、仓库版本未配置明文网络流量，常规图片处理不依赖上传服务器。

请注意：如果你发布包含 EXIF 信息的作品，图片中可能会展示拍摄时间、相机参数或位置信息。分享前请确认这些信息是否适合公开。
